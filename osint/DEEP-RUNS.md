# Six additional discovery profiles: fourteen configured runs

This expansion retains the first eight profiles and adds six narrower retrieval profiles. They use the existing engine and workflow, not six duplicate crawlers or paid models. The current combined output budget remains 5,000,000 bytes, at most 50 exported representations per profile, and a 120-second soft scan budget. Additional profiles may reduce effective coverage within that budget. The workflow reports truncation and fails publication on output-budget overflow. Old README references to eight describe the initial deployment; the configured profiles.json is authoritative.

## Added runs
- Vendor data ownership, expiration, export and retention clauses in software contracts.
- Legacy military cleanup and groundwater records related to Atlas or Belvoir.
- Public-land leases, royalties, grazing and wind-revenue references.
- Stage I/II, trans-basin water trades and water-rights references.
- Substitute, amended and superseded decision documents. This retrieves passages; it does not perform semantic version comparison.
- Utility-rate classes, outside-city provisions and negotiated-service language.

## Verification discipline
The initial eight-profile run published a checkpoint scanning 802 representations from 206 source objects, with 785 captured source objects recorded in the ledger. Those are different counts, not proof that every captured object was text-indexed. The six new profiles have not run before this deployment. Public-web source verification in this conversation is separate from automated corpus results; a web source is not automatically mirrored by adding its terms here. Zero hits can reflect incomplete ingestion/OCR rather than absence of the underlying event. Preserve exact passages, original URLs, revision-pinned copies, page/character locators, date context and uncertainty. Do not claim these are previously unknown, infer wrongdoing from keyword matches, or publish private utility-customer records or personal dossiers. No new sources, paid services, subscriptions, LFS, billing changes or repositories are enabled by this expansion.
